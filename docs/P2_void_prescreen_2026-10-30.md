## 1. 原提案（要检验什么）

> leak VOID（历史组门阻滞器）是否等价于把**有效占据**压到阈值以下？
> 做法：仅用现有 Dx2 leak 探针协议，报告「VOID 率–籽通过」相图；预筛规则写入下一步任何门控加压跑的硬闸。
> 杀法：VOID 率与 hold 失败无单调／阈值关系 → 不得把 leak 写成渗流空位。

## 2. 归档核对结果：**该相图不可生成**

### 2.1 事实

| 项 | 归档值 |
|----|--------|
| VOID 籽数 | **0 / 8** |
| 8 籽 `leak_mean` | **全部 0.5**（5 次重复样本全为 0.5） |
| `leak_sd` / `leak_se` | **0.0 / 0.0**（8 籽皆然） |
| VOID 线 | **0.6**（`A_empirical+0.10`；N=2 下 chance=0.5） |
| Dx2 遗产线 | 0.35（N=4 标定，**未放宽**，也未套用） |
| 分母 | 8，未缩 |
| A 臂 / C 臂 leak | 同为 0.5、sd=0.0 |

### 2.2 为什么这直接杀死相图

相图要求两个轴都有变异：\(X\)＝缺陷密度、\(Y\)＝通过／失败。
本归档 \(X\) 的方差**恰好为 0**（8 籽 × 5 重复，全部 = chance）。

> **零方差的自变量不能估计任何 \(X\)–\(Y\) 关系**——不是「关系弱」，是**不可识别**。
> 因此「VOID 率 × 籽通过」相图在本归档上**不存在可画的点**，硬画出来的只能是单点（0/8, 1/8）。

### 2.3 更麻烦的一层：`leak ≡ chance` 曾有两种解释，现已定案为第二种

一个**恒等于 chance** 的探针，至少对应两种世界：

| 解释 | 含义 | 后果 |
|------|------|------|
| (a) 真无泄漏 | 探针有功效，且确实测不到泄漏 | VOID=0 是**有信息**的阴性 |
| (b) 探针无功效 | 探针设计在此环境读不出任何信号 | VOID=0 是**空转**，不构成阴性 |

**2026-10-30 已定案：(b)。** 见 `PROBE_AUDIT_leak_2026-10-30.md`。下列读数来自外部实验床 `percolation_lab/probe_v2.py`（**未收入本包**，本页不重跑）——

- E2 版探针的特征矩阵 **`max|X| = 0.000`**（它只取 cue 块，又跳过所有 cue 可见行与含 cue 的窗口，而 cue 不可见时 cue 块就是全零）；
- 故对**任何** agent 都返回类别先验（实测 0.4709），`sd=0`；
- 同一探针喂入 cue 全程可见的观测时可达 **1.0000** → 探针本身有能力，是取数方式把它清零。

因此：**`VOID 0/8` 是仪器空转，不是「无缺陷」。** 这也解释了为什么 8 籽 × 5 次重复的 `leak_mean` 会精确等于 0.5 且方差为零。

> 与 P1/P3 的关系：`goal_register_p1p3` 的 P3 四维预筛**有** fixture 故意命中（`P1P3_SMOKE_REPORT.md`：全 fixture 命中 4、干净样例 0 命中、`--strict` 退出码 2）。
> 同一套「故意注入必须报警」的纪律，**E2 的 leak 探针没有**。这是可补的缺口，且已补（`probe_v2.py`）。

## 3. 裁定

| 结论 | 内容 |
|------|------|
| **P2 原样不可执行** | 以现有归档生成 VOID–通过 相图 = 制造数字。**先杀。** |
| **根因已定位并复现** | 不是「数据不够」，是 **E2 版探针特征恒零**（`max|X|=0.000`，见 `PROBE_AUDIT_leak_2026-10-30.md`）。Dx2 权威报告在 S1 上有效（籽均 0.30–0.35，有方差）；那不是本页在 S2c 上的复测。 |
| **已修（外部实验床，未收入本包）** | `percolation_lab/probe_v2.py`：恢复 Dx2 口径 + 阳性对照 + 拆两个泄漏通道；该床实测给出非退化读数（0.644–0.708）。本仓库**不**据此改阈值、**不**开新跑。 |
| **叙事不得先行** | 修好探针**之前**，禁止把 leak 写成「渗流空位」；修好之后，也**禁止**把某一批的 VOID=0 写成「无缺陷」——须先看阳性对照是否过。 |

## 4. 要让 P2 变得可识别：三步（每步都需单独授权）

| 步 | 内容 | 性质 | 是否需新预注册 |
|----|------|------|----------------|
| **P2-a** | 给 leak 探针加**阳性对照**：人为把目标信息以已知强度注入（例：把 goal 标签以可控强度泄漏进撤除窗／探针输入），要求探针在注入档位单调报警；同时保留干净样例要求零报警 | **工程冒烟**（`ENGINEERING_*_NOT_*PASS`），不产生科学数字 | 否（属探针标定，不动阈值） |
| **P2-b** | 若 P2-a 通过（探针有功效）：设计「缺陷诱导」扫描——把注入强度作为**缺陷密度轴**，观察 hold 通过率是否随缺陷上升而**先平后崩**（阈值型）还是**线性下滑** | **科学实验** | **是**（新 ID，新冻结阈值；**不是**放宽 VOID 线，而是**制造**缺陷） |
| **P2-c** | 若 P2-a 不通过（探针无功效）：**停止缺陷叙事**，把 leak 只当「未标定的探针」，P2 结案为「不可测」 | 结案 | 否 |

**纪律（沿用，不许动）**：
- 禁止放宽 leak VOID 0.35（N=4 遗产）或 `A_emp+0.10`（N=2）；
- 禁止缩 VOID 分母（恒 8）；
- **禁止**把「制造缺陷」与「放宽线」混为一谈——前者是自变量，后者是作弊；
- P2-b 若开，必须新冻结阈值，且不得回头改 E2 判决。
