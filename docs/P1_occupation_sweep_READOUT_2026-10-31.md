## 2. 为什么 `q` 坏掉：三个结构性缺陷

`q = 1 − every.dwf / sparse.dwf`。

**(a) 奇点恰好在有物理意义的地方。** `p_cue=1.0` 时 agent 完全不再用 cue（`wf_opp` 与 `wf_same` 只差 2.6e-5），两条臂的 `dwf` 同时趋于 0 → 比值 0/0 → NaN。
**40/40 单元全灭**，占 200 单元的 20%。这不是协议坏了，是**效应真的归零**，而比值表达不了「归零」。

**(b) 缺失非随机。** `p=0.25` 有 30% NaN，而塌陷的单元正是低 `q` 的单元。幸存者均值被系统性抬高——这正是报告里 `p=0.25` 看着「回升到 0.6211」的原因。

**(c) 低档饱和。** 同籽同 rep 跨档逐位相同的组数：

| 档对 | 逐位相同的组数 |
|---|---|
| 0 与 0.02 | 5/40 |
| 0 与 0.08 | 10/40 |
| **0.02 与 0.08** | **16/40** |

权重明明不同（`wf_healthy` 变了），`wf_opp/wf_same` 却逐位相同——探针在这段区间**没有动态范围**，x 轴没推动 y 轴。

三件事合起来：`q` 的可定义率是 `95% / 92.5% / 100% / 70% / 0%`。**五个档里有三个不完整或全空。**

## 3. 换序参量：`sparse.dwf` 本身

`sparse.dwf` = 把潜状态 `pin` 到**相反目标质心**与**相同目标质心**时，目标导向动作比例的差。
它是「潜状态对行为的因果效应」，有界 `[-1,1]`，**200/200 全部有定义**。

| `p_cue` | n | mean | sd | median | min | max |
|---|---|---|---|---|---|---|
| 0 | 40 | +0.6120 | 0.1389 | +0.6454 | +0.009 | +0.674 |
| 0.02 | 40 | +0.6009 | 0.1793 | +0.6504 | −0.044 | +0.674 |
| **0.08** | 40 | **+0.6505** | **0.0110** | +0.6501 | +0.620 | +0.669 |
| **0.25** | 40 | **+0.4292** | **0.2845** | +0.6380 | −0.016 | +0.667 |
| **1.0** | 40 | **−0.0036** | 0.0315 | +0.0000 | −0.101 | +0.063 |

`p=0.08` 的 sd 只有 **0.011**——40 次运行挤在 0.620–0.669，这是一个非常硬的「有序平台」。
`p=1.0` 全部塌到 0 附近，sd 0.03。`p=0.25` 的 sd 0.28 **不是噪声，是双峰**。

### 二值序参量：每次 run 落在哪一簇

判活线取 `sparse.dwf > 0.5`：

| `p_cue` | 存活 | 比例 | Wilson 95% CI |
|---|---|---|---|
| 0 | 37/40 | 0.925 | [0.801, 0.974] |
| 0.02 | 37/40 | 0.925 | [0.801, 0.974] |
| 0.08 | 40/40 | 1.000 | [0.912, 1.000] |
| **0.25** | **24/40** | **0.600** | **[0.446, 0.737]** |
| 1.0 | 0/40 | 0.000 | [0.000, 0.088] |

**判活线敏感性**：把线从 0.3 挪到 0.6，计数几乎不动（`26/25/24/24`）。因为两簇之间有一大段空隙（0.22 → 0.63 之间只有 2 个点）。**这条曲线不依赖阈值选择**，这是它最硬的地方。

## 4. 双稳是**籽内**的，不是籽间异质性

这是整份数据里最有信息量的一处。`p=0.25` 的 40 个原始值，按籽排：

| seed | 五次重复 | 籽内 sd |
|---|---|---|
| 200 | 0.633 0.637 0.648 0.651 0.659 | 0.010 |
| 205 | 0.633 0.644 0.651 0.663 0.667 | 0.014 |
| 210 | −0.010 −0.004 0.003 0.005 0.104 | 0.048 |
| **211** | **0.004 0.344 0.427 0.649 0.657** | **0.268** |
| 212 | −0.016 0.006 0.080 0.201 0.223 | 0.110 |
| **216** | **0.010 0.094 0.139 0.651 0.662** | **0.319** |
| 218 | 0.640 0.642 0.643 0.648 0.660 | 0.008 |
| 219 | 0.630 0.638 0.640 0.645 0.665 | 0.013 |

**同一个籽、同一套超参、只换 episode 种子，就横跨整个区间。** 这排除了「某几个籽天生弱」的解释：
在 `p=0.25`，**系统本身有两个吸引子**，一次训练落在哪一个有随机性。

对照：`p=0.08` 时 8 个籽 40 次运行**全部**在 0.620–0.669；`p=1.0` 时**全部**在 −0.10–0.06。
所以：

```
p ≤ 0.08   有序（寄存器必存活）
p = 0.25   混合（P≈0.6，籽内双稳）
p = 1.0    无序（寄存器必溶解）
```

## 5. 能说什么 / 不能说什么

**能说**

1. `q` 在本床不可用（奇点 + 非随机缺失 + 低档饱和），报告的形状判定作废。
2. 换成探索性序参量 `sparse.dwf` 后，存在一条**可重复、对判活线不敏感**的剂量–反应曲线。这**不是** \(p_c\)。
3. 过渡区里**同籽内分裂**——在这个探索性读出上，这是双稳样的证据，不是测量噪声。它**不是**渗流临界点，也**不是**确认性结果。
4. 早停是致命的：同一籽 `191 epoch` 给 `ratio=0.967`（q=0.033），`800 epoch` 给 `ratio=0.517`（q=0.483）。**训练预算必须冻在 800**。

**不能说**

- **不能说测到 `p_c`**。过渡区间只被夹在 `(0.08, 1.0)`，里面只有 `0.25` 一个点。一个点定不出阈值。
- **不能叫渗流**。本床没有关联长度、没有簇结构、没有有限尺度标度。`p_cue` 调的是「cue 出现的频率」，不是「占据格点」。
- **不能算确认性结果**。换序参量是看到数据之后做的决定 → 本读出是**探索性**的，不继承原预注册的确认性地位。
- 不改变 E2 的既有判决。E2b 归档不在本包，其数字**未核验**，本读出也不改它。S3 仍 CLOSED。本页不授权新的科学跑。

## 6. 一个概念上的纠正（比数字更重要）

`p_cue` 的语义是「每个非 switch 步，以概率 `p_cue` 额外显示一次 cue」。未触发的步 cue 块是全零。
所以这**确实**是一条「写入槽位被填的比例」的轴——按这个口径，它是个合法的占据量。

但它**不是渗流**，原因有两条，都不在数据里、在结构里：

**(a) 没有可连通的结构。** 占据发生在**时间轴**上的一维密度，没有图、没有邻接、没有簇。
渗流的三个观测量是序参量、阈值、**发散的相关长度**。本床第三个**根本不可定义**——
这也是外部预注册草案（**未收入本包**，不是本仓库的冻结协议）里 RQ3 已经写死排除的那一条。一维密度上的「阈值」只是剂量–反应曲线的拐点，**不是**晶格渗流的 \(p_c\)。

**(b) 机制是「冗余溶解寄存器」，不是「连通性失效」。** 当 cue 几乎每步都在，
agent 不需要维持内部寄存器——直接读输入就行。序参量掉下去是因为**持有变得不必要**，
不是因为某条通路断了。这是**竞争吸引子**问题，不是连通性问题。

所以本结果的正确名字是「**寄存器维持的双稳功能转变**」（探索性读法），不是「渗流相变」，也不是 \(p_c\)。
要让它变成渗流问题，必须让 cue 经过一个**能被切断的结构**，而不是调一个密度。那样的设计**不在本包**，本页**不授权**去跑它。`q` 仍作废；`sparse.dwf` 仍只是探索性序参量；**S3 仍 CLOSED**。
