## 1. 问题陈述（一句话）

现行实验序列可能**过度押注「内部自治特征」**（可学习门、内部状态承载、自选目标寄存器等），而灵感源更像是**半自主**：行为可由**外部宏观暗示**牵引，且该暗示往往**难以证伪**。

本备忘不改写任何已结案数字；不授权开 E2 / S3；只提出下一阶段的**分类问题**。

---

## 2. 批判：内部自治特征是否被高估

| 观察 | 含义（决策用） |
|---|---|
| 阶梯大量操作化落在「内部状态 / 门控 / 寄存器」上 | 验收叙事偏「agent 内部是否长出自治部件」 |
| L2-teacher / 发育脚手架 / 指定通道（C）均可过玩具 | 成功常依赖**可撤除的设计者注入**，不等于内部自治已立 |
| L2-self 组门与 E2 gate **当前未满足** | 在未过 E2 前，不宜把「内部自治」当作已逼近的主结论 |

**风险**：把「设计者可装可拆的内部特征」误读为「系统已具备不可还原的自主」。  
**纪律**：脚手架可拆则非自治载体（与元分析过滤原则同向）；本备忘**不**据此宣称已证或已否。

---

## 3. 灵感形态：半自主，而非全内生

若参照灵感侧（人类/组织决策），常见模式是：

1. **外部宏观暗示**给出方向或约束（同伴、环境节律、制度、任务景观）；
2. 主体在暗示下做局部选择与修订；
3. 旁观者很难区分「自发」与「被暗示牵引」——暗示往往**软、可否认、难做严格阴性对照**。

因此，「启发是否成立」与「实验室能否用内部自治特征单独复现」**不是同一问题**。  
若外部暗示在定义上难证伪，则单靠加严内部特征清单，可能**答错题**。

## 4. Stance A 已给出的分界（须沿用，勿神秘化）

权威表 Stance A（现行）：

- **禁止**：适应度**直接**惩罚状态漂移（无 `‖Δs‖` / s 稳定性付款）。
- **切换目标导致进度损失** = **世界动力学 / 环境收益结构**，**不是**外挂奖励脚手架；与非神创论兼容。
- Stance B（争议注）更保守：工程化「切换即损」亦可视为预装偏好；Stance B 下即便 L3-a PASS 亦不计第 3 级。

**决策含义**：项目**已经**承认一类「外部结构」可合法进入世界，而不必记为内部奖励作弊。  
下一问不是「要不要更多神秘内生」，而是：**哪些外部结构算可撤除的设计者脚手架，哪些算不可撤回的世界承诺。**

## 5. 决策题：是否拆分两类「外部」

请决策层明确是否将后续工作（含 E2 / S3 协议修订）强制拆成两栏验收：

| 栏 | 工作定义（草案） | 验收态度 |
|---|---|---|
| **A. 设计者脚手架** | 可按协议**撤除**而不改世界定律：教师标签、发育硬约束、指定通道接线、逐步 CE、可关断的 cue 注入等 | 过线 = 工程可达；**禁止**写成发现 / 内生自治 |
| **B. 不可撤回的世界承诺** | 写入环境动力学后**不可**在验收期悄悄关掉而不改任务：切换损失、资源/毒性景观、同伴交互可得的目标内容等（Stance A 已覆盖切换损失一类） | 可计入「世界/同伴来源」；仍须无稳定性付款；**仍禁止**夸大成系统发明目标 |

**待拍板**：

1. 是否采纳上表二分，作为 E2 / S3 文档与报告的**强制栏目**？  
2. 「半自主」是否列为**显式中间档**（外部宏观暗示 + 局部内化），而非仅用「全内生 vs 全外挂」二元叙述？  
3. 对「外部宏观暗示」——若难做严格证伪——是否要求：**只做存在性/可干预上界**，不做「已排除暗示」类强宣称？

## 补充（2026-10-11 ~15:00 CST）：协变补全假说

**用户提出**：联系感可能是看的人主动补全的产物。两个概念之间只要有词或过程细节上的弱关联，就会被补成强联系；只要去找，几乎任何两样东西之间都找得到联系，差别只在强弱。进一步推测：神经网络也许没有自主性，只是协变关系拉着它补全，补全又制造出强联系。

**与 S1g 的对应（只是解读，不是结论）**：GRU 8/8、普通 RNN 0/8，差别在于有没有门控这种结构先验，能让回报中的协变关系把线索拉进记忆。按协变补全的读法，「自主」更像是结构先验加上协变压力之后的补全，而不是凭空发起。

**可证伪化方向（交决策层判断）**：
1. 在行为上，「协变补全」与「有自主性」可能分不开（难以证伪）。实验能做的是把它改写成撤除检验：撤掉协变拉动（打乱回报和线索的相关性，或者冻结之后换一个协变结构的世界），看已经长出来的寄存器是否保留、是否仍然必要。
2. 在 L3-a 里区分两种情况：目标选择是本局历史协变的补全，还是独立于当下协变的持续性选择。
3. 不预设结论，也不把这一条写成「自主性不存在」。

## 补充（2026-10-11 ~15:10 CST）：协变涌现（所指沟通与能指链偏移）

**用户梳理（原意整理）**：
1. 单纯词语（所指）本身没有固定向量。沟通双方的能指链天然存在偏移；不和相似结构比照时，这种偏移很难被察觉。
2. 一旦比照，双方持续校正自身理解，校正永不停止；大量校正累积，宏观上呈现为涌现。这个互相调整的过程称为**协变**（你变我也变，我变了，我眼中的你也变）。
3. 微观层面：人会主动补全联系（因为期望建立关联），这种补全与整体协变的方向一致。
4. **涌现 ≠ 达成一致**。涌现是协变、持续对照校正、微观补全共同产生的宏观现象，建立在客观物质联系之上。

**对实验设计的含义（解读，不是结论）**：
- 目前的 L2/L3 尺子都在测单个体内部（可撤除寄存器、必要性），最多测到微观的「拉动补全」，测不到宏观的「协变涌现」。
- 早先的通信线（Comm、Rita 听者 held-out）问的是「能否传信号」，没有问「互相校正能否产生新的趋向」。

**候选方向（交决策层判断，未开）**：
- 两个（或多个）可学习体在共享世界中相互比照、持续校正，检验能否出现单体训练中没有的目标结构或趋向。
- 验收要区分「收敛到一致」与「持续校正中长出新结构」，后者才算本条意义上的涌现。
- 与非神创论边界一致：目标来自同伴/世界允许，但设计者不得写入目标内容。
